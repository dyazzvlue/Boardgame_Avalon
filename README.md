# Avalon — 阿瓦隆桌游模拟器

一款基于 [阿瓦隆桌游](rules.md) 规则实现的模拟器，支持 5–10 人混合对战（真人玩家 + AI 对手），提供本地图形界面与 [GamePlatform](../gameplatform) 联机模式。

## 功能特性

- **图形界面**：基于 pygame，分辨率 1280×800，圆桌布局显示所有玩家、任务进度与投票历史
- **完整角色**：梅林、派西维尔、刺客、莫德雷德、莫甘娜、奥伯倫、亚瑟的忠臣、莫德雷德的爪牙，支持 5–10 人任意人数配置
- **混合对战**：至少 1 名真人玩家 + AI 对手，自由配置
- **信息安全**：角色信息仅在本地单独展示，联机时通过私信通道下发，绝不广播给他人
- **AI 对手**：基于投票历史的信任度推断，具备组队、投票、执行任务和刺杀决策
- **联机支持**：与 [GamePlatform](../gameplatform) 框架无缝集成，浏览器即可多人联机
- **夜晚阶段动画**：开局按照阿瓦隆规则依次展示各阵营的信息窗口

## 快速开始

### 本地图形界面（推荐）

```bash
cd Avalon
python3 gui_main.py
```

启动后进入配置界面，设置玩家人数（5–10）、各玩家姓名及真人/AI，点击**开始游戏**。

### 文字模式（CLI）

```bash
cd Avalon
python3 main.py
```

默认 5 人局，第 1 位为真人玩家，其余为 AI，适合快速测试逻辑。

### 联机模式（GamePlatform）

```bash
cd gameplatform
AVALON_PATH=../Avalon uvicorn framework.server:app --host 0.0.0.0 --port 8000
```

浏览器访问 `http://localhost:8000`，在大厅选择"阿瓦隆"创建房间，5–10 名玩家依次加入即可开始。

## 操作指南

### 配置界面

1. 用 **＋／−** 按钮调整玩家人数（5–10）。
2. 点击玩家名字输入框修改姓名。
3. 点击**真人 / AI** 切换按钮选择类型（至少保留一名真人）。
4. 点击**开始游戏**。

### 游戏界面布局

```
+--------------------------------------------+----------+
|                   顶部状态栏                |          |
+--------------------------------------------+  我的角色 |
|                                            +----------+
|              圆桌（玩家头像）               |          |
|        队长 👑 / 队伍成员 高亮              |  投票历史 |
|                                            |          |
+--------------------------------------------+----------+
|               任务进度轨道（R1–R5）         |          |
+--------------------------------------------+----------+
|                    操作面板                            |
+--------------------------------------------------------+
```

### 操作面板说明

| 阶段 | 操作 |
|------|------|
| **夜晚（show_role）** | 查看自己角色与阵营情报，点击"我知道了"确认 |
| **提名队伍（select_team）** | 点击圆桌上的玩家头像选中/取消，选满后点击"确认队伍" |
| **全体投票（vote_team）** | 点击"赞成"或"反对" |
| **执行任务（play_mission）** | 点击"任务成功"；坏人可选"任务失败" |
| **刺杀（assassinate）** | 刺客从候选列表中选择目标 |

### 快捷键

| 按键 | 功能 |
|------|------|
| `R` | 游戏结束后返回配置界面 |
| `ESC` | 游戏结束后退出 |

## AI 说明

AI 通过**投票历史**累积信任度，综合判断玩家阵营倾向后做决策：

| 阶段 | AI 策略 |
|------|---------|
| **组队（好人队长）** | 优先选择信任度高的玩家；好人连胜 ≥2 次时适当冒险 |
| **组队（坏人队长）** | 尽量带入至少一名坏人同伴；好人领先时改变策略 |
| **投票** | 坏人队伍中含有坏人时高概率赞成；好人根据平均信任度决定 |
| **执行任务** | 坏人在好人领先 ≥2 次或进入关键轮时选择出失败牌 |
| **刺杀** | 统计全局投票行为，评分最高的好人玩家即为刺杀目标 |

## 联机模式

Avalon 通过 [GamePlatform](../gameplatform) 框架支持 WebSocket 多人联机：

- 框架自动管理房间创建、玩家加入、断线接管（AI 托管）
- 私密信息（角色）通过单人通道下发，其他玩家不可见
- 前端渲染：`gameplatform/framework/static/games/avalon.js`
- 后端插件：`gameplatform/framework/games/avalon/plugin.py`

启动命令：

```bash
cd gameplatform
MANILA_PATH=../Manila AVALON_PATH=../Avalon \
  uvicorn framework.server:app --host 0.0.0.0 --port 8000
```
